### 📌 Featured Projects

**🏠 Stashup — Bengaluru House Price Prediction System**
- End-to-end ML pipeline on 13,320 real Bengaluru house listings, with engineered features (bath-per-BHK, sqft-per-BHK) and input validation with realistic sanity checks.
- Compared Linear Regression, Random Forest, and XGBoost — best performance with XGBoost (R² ~0.88, MAE ~₹18.5L).
- Deployed as a live **Streamlit app** predicting prices from location, size, and amenities, showing the model's typical error margin alongside each estimate.
- 🔗 [Live App](https://kritikap2406-netizen-stashup-bengaluru--streamlit-appapp-k80y5b.streamlit.app)

**🎬 Swirl — An Extensively Designed Recommendation System** *(in progress)*
- Hybrid movie recommendation platform combining popularity-based and content-based filtering, using TF-IDF vectorization and cosine similarity on movie metadata.
- Full-stack build: **React + Tailwind CSS** frontend, **Flask** backend.
- Features: user authentication, genre-based personalization, searchable movie database, a "bucket list" (watchlist), and a personalized homepage based on user preferences.
